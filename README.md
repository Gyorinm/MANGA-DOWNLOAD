# مكتبة — قارئ مانهوا دون إنترنت

تطبيق Flutter يبحث في مصادر متعددة، يُنزّل المانهوا كاملة (الغلاف والفصول والصفحات) إلى الجهاز، ثم يعرضها للقراءة بلا اتصال.

## التشغيل

```bash
flutter pub get
flutter run
```

الحد الأدنى: Flutter 3.19 / Dart 3.3.

## المعمارية

أربع طبقات، والاعتماد يتجه إلى الداخل فقط: الواجهة ← المستودع ← المصادر/القاعدة ← النطاق.

```
lib/

│   ├── app.dart                  التنقّل بين التبويبات الثلاثة
│   └── theme.dart                الألوان والخطوط
│
├── core/                         أدوات لا تعرف شيئًا عن المانهوا
│   ├── http/http_client.dart     مهلات وإعادة محاولة للأخطاء العابرة
│   ├── storage/file_storage.dart المالك الوحيد لمسارات القرص
│   └── utils/result.dart         نتيجة موحدة ورسائل خطأ بلغة المستخدم
│
├── domain/entities/              كيانات نقية: Manga و Chapter
│
├── data/
│   ├── sources/
│   │   ├── manga_source.dart     العقد الذي يطبّقه كل مصدر

│   │   ├── source_settings.dart  اختيار المستخدم للمصادر المفعّلة
```

### قرارات هندسية

**المصدر واجهة، لا حالة خاصة.** كل موقع يطبّق `MangaSource` بخمس دوال. البحث يوزَّع على كل المصادر بالتوازي، وفشل مصدر لا يُسقط البقية. إضافة موقع جديد = ملف واحد + سطر في قائمة `sourceRegistryProvider` داخل `providers.dart`.

**المستخدم يختار مصادره.** شاشة «مصادر التحميل» (زر الضبط في شاشة البحث) تُفعّل المواقع وتُعطّلها، ويُحفظ الاختيار على الجهاز. يُحفظ المعطَّل لا المفعَّل، فأي مصدر جديد يظهر مفعّلًا افتراضيًا، ويبقى دائمًا مصدر واحد على الأقل. وتعطيل مصدر لا يمسّ ما حُمّل منه سابقًا.

**الفصل هو وحدة الاستئناف.** لا يُعاد تنزيل صفحة موجودة على القرص؛ يُنزَّل كل ملف باسم `.part` ثم يُعاد تسميته، فلا تبقى صور نصف مكتملة تُفسد القراءة. كل تغيّر في الحالة يُكتب في قاعدة البيانات فورًا، فإن أُغلق التطبيق استأنف `resumePending()` من حيث توقّف.

**التزامن محدود بثلاثة فصول.** كافٍ لاستغلال الشبكة، ولا يخنق اتصال المستخدم ولا يستفز المصدر.

**SQL مكتوبة يدويًا.** لا build_runner ولا ملفات مولّدة؛ المخطط والترقيات مقروءة سطرًا بسطر، والفهارس موضوعة حيث تمرّ الاستعلامات فعلًا.

**القارئ لا يلمس الشبكة.** يقرأ من `FileStorage` فقط، والصفحات مُصفّرة (`0001.jpg`) ليطابق الترتيب الأبجدي الترتيب الرقمي.

**لا فقد للتقدّم عند التحديث.** `mergeChapters` تدمج قائمة الفصول القادمة من المصدر دون أن تمسّ حالة التحميل أو آخر صفحة مقروءة.

## بنية التخزين

```
{applicationSupport}/library/{mangaKey}/cover.jpg
{applicationSupport}/library/{mangaKey}/{chapterId}/0001.jpg
```

`mangaKey` هو `sourceId::remoteId`، مُنظَّف ليصلح اسم مجلد على كل الأنظمة.

## المصادر والحقوق

المصدر المضمَّن هو **MangaDex** عبر واجهته البرمجية الرسمية المجانية. هذا اختيار مقصود: واجهة معلنة ومستقرة بدل كشط HTML هشّ، ومحتوى ذو وضع قانوني أوضح.

قبل إضافة أي مصدر جديد، تحقّق من شروط استخدامه ومن حقوق النشر؛ متاجر التطبيقات تحذف بانتظام التطبيقات التي توزّع محتوى غير مرخّص.
